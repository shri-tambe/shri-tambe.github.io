# CS 6950: Applied AI Agent Systems

**Graduate Seminar — 3 Credit Hours**
**Instructor:** Shrikant Tambe \| [ORCID](https://orcid.org/0009-0003-3432-3852)

A course bridging 20 years of distributed systems engineering with multi-agent AI orchestration. Students build, observe, and harden AI agent systems using real-world patterns from production deployments at scale.

**Prerequisites:** Graduate-level distributed systems or ML. Python proficiency.

**Grading:** 40% Assignments \| 20% Midterm \| 40% Final Project

| Week | Topic | Key Reading |
|------|-------|-------------|
| 1–2 | Foundations: agent architectures, MCP, A2A | Yao et al., ReAct (2023) |
| 3–4 | Orchestration: topologies, event-driven coordination | Ju et al., Self-Repair (arXiv:2502.15153) |
| 5–6 | Observability: distributed tracing, AER, D-AER | AER (arXiv:2603.21692); Tambe, D-AER (2026) |
| 7 | **Midterm** | |
| 8–9 | Reliability: Cognitive SLOs, chaos engineering | Pal & Bhattacharya, Stochastic Gap (arXiv:2603.24582) |
| 10–11 | Production: cost attribution, model routing, scaling | In et al., Failure Attribution (arXiv:2603.25001) |
| 12–13 | Advanced: security, human-agent handoff, drift | |
| 14 | **Final Project Presentations** | |

**Final Project:** Design, build, and deploy a multi-agent system with full observability, 3+ Cognitive SLOs, and a chaos experiment.
